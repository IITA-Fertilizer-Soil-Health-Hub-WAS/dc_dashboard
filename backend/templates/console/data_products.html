Endpoints

EndpointReturns
GET /api/v1/projects/Projects you can access, with submission & open-issue counts.
GET /api/v1/projects/<code>/submissions/Reviewed submissions (paginated). Filters: ?form= ?event= ?since=YYYY-MM-DD ?values=1.
Incremental pull for ETL: ?updated_since=<ISO> returns only rows changed since that timestamp, ordered by updated_at — checkpoint on the last updated_at you saw and pass it back next run.
GET /api/v1/projects/<code>/flags/Validation flags (default open; ?status=ALL).
GET /api/v1/projects/<code>/kpis/The project's M&E summary.
