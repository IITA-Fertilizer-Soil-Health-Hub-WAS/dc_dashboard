rocket_launchOnboard a new projectAdmin · Coordinator
  1. Sidebar → Manage projects → Onboard project (or Set up → Structure).
  2. Pick the collection server (ODK Central / ONA / Kobo), then Find projects.
  3. Choose the server project — already-onboarded ones are flagged to avoid duplicates.
  4. Name it, set the owner, confirm its forms, and finish. Field names import automatically.
syncGet a form's fields into the platformCoordinator
Fields import automatically at onboarding and on every sync. To refresh after a form change: Set up → Project setup → Validation rules → New rule → Import fields & names, or just run Sync now on the project.
ruleBuild a validation ruleCoordinator
  1. Set up → Project setup → Validation rules → New rule.
  2. Pick the form, then a rule type: range, statistical outlier, cross-column sum (e.g. shares = 100), duplicate id, conditionally-required, or reference/lab match.
  3. Fill the plain-English settings (no JSON), watch the live summary, hit Test rule to see how many current records it would flag, then Save.
datasetImport reference data & check coverageCoordinator
  1. Set up → Reference data → Import a CSV — a sampling frame, lab results, or a lookup — and name its key column (e.g. sample_id).
  2. Open Coverage, pick the submission field holding the same id, and see matched / missing (never submitted) / unknown ids.
  3. Add a reference-match rule to flag unknown ids, or a reference-compare rule to cross-check field vs lab values.
rate_reviewReview & approve submissionsCoordinator · QC
Open a project → Review. Open a submission to inspect it, then Validate / Endorse / Request-edit / Decline from the row. Every action is logged in the Review log. Flagged issues appear on the Issues tab.
buildFix flagged data (as an enumerator)Enumerator
Open My submissions — records with issues list exactly what's wrong. You'll also get a weekly email of corrections needed. Recollect / correct in ODK Collect; the fix flows in on the next sync.
apiPull data into another tool (API)Coordinator · Admin
Sidebar → Data products. Generate an API token, then call /api/v1/projects/<code>/submissions/ (paginated, filterable, ?values=1 for field values). Everything is scoped to what you can access.
insightsMonitor progress (M&E)All
Open a project → M&E. Switch views (Summary / Quality / Team quality), pick a time window, and read submissions-vs-target, approvals, open issues and the quality score. Export CSV / GeoJSON from the top of the page.
